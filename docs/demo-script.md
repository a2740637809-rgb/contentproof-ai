# 三分钟演示脚本

## 0:00–0:25｜问题与证据

展示 4 篇常德融媒公开署名作品链接。说明项目不复制全文，而是把公开元数据和短摘要转成可核验作品证据。

## 0:25–0:55｜任务与来源卡

录入平台、受众、语气、篇幅和禁用语；打开来源卡，强调每条事实都有原文链接，缺失信息必须标记待核验。

## 0:55–1:25｜可重试工作流

展示事实抽取、提纲、初稿、平台改写四步轨迹。模拟提纲步骤失败，说明系统只重试失败步骤及后续步骤，保留已完成事实输出。

## 1:25–2:05｜提示词版本对照

比较 v1 与 v2 在同一批案例上的五维评分。说明提示词不可覆盖修改，每次调整生成新版本，差值和人工决定可导出 CSV。

## 2:05–2:35｜规则与人工终审

展示缺失事实、禁用语、篇幅越界等失败案例。强调模型评分仅供参考，最终稿由人工接受、修改或拒绝。

## 2:35–3:00｜结果与局限

展示 4 个真实样本、20 条用例、2 个提示词版本、9+ 后端测试和前端生产构建。说明小模型能力有限，项目价值在于证据链、可复现流程和明确的人机边界。
