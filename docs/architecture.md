# 系统架构

## 边界

```text
React 工作台
  │ REST / JSON
FastAPI ── SQLite
  │
  ├─ 显式工作流状态机：facts → outline → draft → adapt
  ├─ 确定性规则：事实、禁用语、篇幅
  ├─ 加权评测：5 个固定维度，结果标记为辅助意见
  └─ ModelProvider
       └─ Ollama HTTP API（本地模型）
```

浏览器只负责录入、查看轨迹、比较提示词和提交人工判断。FastAPI 是唯一业务入口，负责校验请求、持久化运行记录并生成报告。

SQLite 保存任务、来源、提示词版本、运行、步骤、评测和人工终审。每个步骤独立持久化；某一步失败后，重试计划从该步开始，已完成步骤的输出不被覆盖。

模型调用位于 `ModelProvider` 接口之后。当前实现是 Ollama，模型服务不可用时不会影响规则引擎和已有数据的查看。模型分数是辅助证据，不替代确定性检查和人工终审。

公开作品数据与生成系统分离。仓库样本只含元数据、链接、短摘要和原创标注，报告只输出项目自己的评测结果。
