# 项目复盘

## 已验证结果

- 建立 4 条公开署名作品记录，每条保留原文 URL、署名、发布日期、短摘要与版权说明。
- 建立 20 条评测案例：4 条真实作品案例、12 条公开来源约束案例、4 条明确失败案例。
- 实现 2 个不可变提示词版本；重复运行种子脚本后数据库仍为 2 条记录。
- 实现事实缺失、禁用语和篇幅范围三类确定性检查。
- 实现事实准确性 35%、结构 20%、可读性 20%、平台适配 15%、风险控制 10% 的固定权重。
- 后端自动化测试和前端组件测试通过，前端可完成 TypeScript 生产构建。

## 设计判断

项目没有把“调用大模型”当作核心成果，而是把来源、提示词、运行步骤、评测和人工决定串成证据链。模型适配层与业务逻辑分离，便于更换本地模型。提示词采用追加版本，避免实验结果失去可复现性。

## 局限

- 本地小模型的语言和结构评分会受模型能力影响，所有模型分数均为辅助意见。
- 当前评测集规模适合作品集演示，不代表统计学基准。
- 公开页面的展示数是平台累计展示数据，不是独立用户数，也不用于推断传播效果。
- 当前版本不包含用户系统、在线发布、云端计费或多人协作。
