# ContentProof AI 使用指南

## 演示模式

1. 选择“立即体验示例”。
2. 在“事实来源”检查公开链接、摘要与核验状态。
3. 在“内容工作流”运行四步证据流程。
4. 在“提示词实验”比较 v1/v2，而不是凭感觉选 Prompt。
5. 在“质量评测”阅读每个维度的理由和证据。
6. 在“人工终审”保存决定并导出 JSON 证据包。

演示数字用于说明产品机制，不代表线上业务统计。

## 本地模式

先启动 Ollama 和 FastAPI，再选择“连接本地模型”。`GET /api/health` 会显示数据库、可用模型与当前选择；连接失败时会返回明确启动命令。

本地模式的运行步骤会逐步持久化。模型失败时，已经完成的上游输出不会丢失，可从失败步骤重新执行。
