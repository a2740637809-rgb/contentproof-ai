# 简历项目表述

## ContentProof AI｜AI 内容生产与质量评测工作台

独立项目｜FastAPI、React、TypeScript、SQLite、Ollama

- 围绕 4 篇公开署名融媒作品构建可核验内容作品集，保留原文链接、署名、日期与短摘要，明确版权和数据口径。
- 设计“事实抽取—提纲—初稿—平台改写”可重试工作流，独立持久化每步状态与输出，支持从失败步骤继续执行。
- 建立 20 条内容评测案例和 2 个不可变提示词版本，覆盖真实样本、平台适配、来源约束及缺失事实等失败场景。
- 实现确定性规则检查与 5 维加权评测，加入人工接受、修改、拒绝终审，并支持 Markdown 报告和实验 CSV 导出。
- 完成 FastAPI 接口、Ollama 本地模型适配和响应式 React 工作台；以后端自动化测试、前端组件测试及生产构建验证交付质量。

> 注：模型评分为辅助意见，最终质量判断由人工终审完成。
