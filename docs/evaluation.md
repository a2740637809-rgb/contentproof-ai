# Evaluation

SignalProof separates deterministic validity from subjective quality.

## Current gate

1. Dataset rows must be valid JSON and contain `id`, `text`, `label`,
   `channel`, and `difficulty`.
2. Every analyzer output must retain the source evidence ID.
3. Classification is reported per label; one aggregate score is never enough.
4. Every failed case is saved in the report.
5. The public README may only display numbers generated by the checked-in runner.

## Dataset scope

Version 1 contains 50 synthetic examples. It is useful for regression testing
the rules baseline, not for estimating production performance. The next
evaluation version should use anonymized, independently labeled examples from
real content workflows and report inter-annotator agreement.

## Metrics

- accuracy;
- per-label precision, recall and F1;
- macro F1;
- evidence coverage;
- latency and manual edit rate when real task tests become available.

## Baselines

- deterministic keyword rules: implemented;
- embedding similarity: planned;
- local LLM structured classification: available as an application adapter,
  but not yet benchmarked on this dataset.

Missing results are reported as missing. They are never replaced with hand-made
scores.
