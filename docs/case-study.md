# Public media case

## Context

The repository includes metadata for four public Changde media articles supplied
by the project owner. The case demonstrates source registration and traceability;
it does not copy full article bodies and does not claim publication performance.

## What this proves

- public sources can be registered with stable IDs and links;
- a brief can cite source IDs instead of detached prose;
- the repository can preserve provenance without redistributing full articles.

## What this does not prove

- that the articles were produced by SignalProof;
- that SignalProof improved readership or editorial efficiency;
- that the current synthetic feedback represents real readers.

Those outcomes require separate editorial task tests and publication analytics.
Until that research exists, the project only claims a reproducible workflow
prototype.
