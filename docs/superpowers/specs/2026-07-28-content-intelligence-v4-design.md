# Content Intelligence Lab V4 产品闭环设计

## 目标

把当前展示型原型升级为可下载、可配置、可运行、可管理的本地 AI 内容研究产品。用户能够管理研究项目、运行内置示例、查看真实轨迹、比较分析方案，并接入自己的模型服务。

## 产品边界

- 保持“从公开评论发现内容需求”的垂直定位，不扩展为通用聊天工具。
- 默认本地运行；远程模型属于用户主动配置的可选能力。
- 不伪造模型准确率、运行耗时、Token 或成本。
- API Key 不写入浏览器持久化存储；V4 首版仅支持后端环境变量引用。

## 核心闭环

1. 创建或打开研究。
2. 导入链接、文本或表格。
3. 选择模型预设。
4. 运行分析并保存轨迹。
5. 人工确认候选主题。
6. 比较关键词基线与当前分析。
7. 生成有证据的内容 Brief。
8. 归档、恢复或删除研究。

## 功能设计

### 项目生命周期

项目支持 `active`、`archived` 两种生命周期状态。项目列表提供重命名、归档和移入回收站；回收站支持恢复和永久删除。永久删除必须二次确认，并清理该项目关联的来源、评论、向量、分析、主题、审阅事件和 Brief。

### 示例研究

系统提供幂等的“加载完整示例”操作。示例包含 8 条评论、清洗结果、一次完成的分析运行、候选主题、证据关联和一份 Brief。重复调用不会创建重复示例。

### 运行轨迹

空状态提供“运行当前研究”和“加载完整示例”两个动作。真实轨迹显示步骤状态、输入/输出数量、分析方法、模型、开始时间、完成时间和证据覆盖率。

### 方案对比

使用同一项目数据比较关键词基线与最近一次分析。没有分析时提供明确动作，不显示空白大卡片。所有指标来自当前项目数据，并保留“不代表通用模型准确率”的提示。

### 模型中心

首版支持：

- 内置规则基线。
- Ollama 本地服务。
- OpenAI-compatible 自定义地址，可覆盖 OpenAI、DeepSeek、OpenRouter、兼容网关等。
- Anthropic 原生接口作为结构预留，不在首版伪装为已验证。

模型配置包含名称、类型、Base URL、模型名、Embedding 模型名、环境变量键名和启用状态。连接测试只返回成功、可用模型和可读错误，不返回密钥。

### 页面密度

- 桌面内容区使用 12 列栅格，常规板块上下间距从约 100px 收敛到 56–76px。
- 工作区空状态最大高度 320px，并附带下一步动作。
- 技术路径改为紧凑的横向流程条。
- 项目列表采用紧凑卡片和操作菜单，避免单卡占满整屏。
- 移动端保留单列，但减少重复说明和装饰性空白。

## 数据与安全

- SQLite 保存非敏感模型配置。
- 密钥只通过后端环境变量读取，例如 `CONTENT_LAB_OPENAI_API_KEY`。
- 自定义地址仅允许 `http://` 或 `https://`。
- 连接测试设置短超时，错误映射为用户可理解的中文。

## 验收

- 项目归档、恢复和永久删除均有后端测试。
- 示例加载两次不重复。
- 空轨迹页可以直接触发分析。
- 模型配置可以创建、编辑、禁用和测试连接。
- 前端全部按钮存在真实行为。
- 桌面、笔记本和手机无横向溢出。
